A QUICK NOTE

What works today

01

Write and edit lyrics

Create a starter draft in Marathi, Hindi or English, then edit it freely. The starter is rule-based and works offline.

02

Create an instrumental sketch

Choose a mood, style, key and tempo. The browser audio engine renders drums, bass, chords and melody and exports a WAV file.

03

Keep your projects private

Saved drafts stay in this browser's local storage. There is no account or cloud sync in this version.

04

Real AI singing is a separate upgrade

AI-generated vocals and full songs require a compatible generation service and a secure server-side connection. Never paste a private API key into a public front-end file.
